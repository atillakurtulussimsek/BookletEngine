# Input PDFs Directory

Place the following files here:

- **front_template.pdf** — Front cover template (with `{{STUDENT_NAME}}` marker)
- **back_cover.pdf** — Back cover page
- **Student PDF files** — One `.pdf` per student (auto-discovered, names extracted from content)

> Student PDFs are ignored by `.gitignore` to protect private data.
> Template files (`front_template.pdf`, `back_cover.pdf`) are tracked.
